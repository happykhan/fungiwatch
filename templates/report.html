Methods

Species selection

The 19 fungal entities from the WHO Fungal Priority Pathogens List (2022) are queried, grouped into Critical (4), High (7), and Medium (8) priority. For genus-level entries (e.g. Histoplasma spp.), the genus name is queried. For Mucorales, the order name is used. For eumycetoma agents, multiple causative genera are queried (Madurella, Medicopsis, Falciformispora, Trematosphaeria). Where NCBI taxonomy has been updated (e.g. Candida glabrata → Nakaseomyces glabrata), both old and new names are queried and results deduplicated by accession.

Assembled genomes

Genome assembly metadata is retrieved using the NCBI Datasets CLI (datasets summary genome taxon). Fields extracted per assembly: accession, organism name, taxonomy ID, release date, assembly level, submitter, and BioSample attributes (collection date, geographic location, host, isolation source). Both GenBank and RefSeq assemblies are included.

SRA WGS runs

Sequencing read metadata is retrieved from the NCBI Sequence Read Archive (SRA) via E-utilities (esearch + efetch). Runs are filtered to library_source=GENOMIC and library_strategy=WGS to include only whole-genome sequencing data. BioSample attributes (collection date, geo_loc_name, host, isolation_source, host_disease), the SUBMISSION center_name, the LIBRARY block (strategy, source, selection), and the PLATFORM block (platform, instrument_model) are extracted from the inline sample metadata in the SRA XML. Placeholder values (missing, not collected, not applicable, unknown, etc.) are treated as absent.

Host categorisation

Each record's BioSample host, isolation_source and host_disease values are joined and matched against keyword lists to assign one of seven coarse categories: human, animal, plant, environment, food, clinical_other (healthcare-associated surfaces and devices), unknown. Both the raw NCBI strings and the derived category are kept in the per-record CSV downloads.

Metadata completeness

For each record (genome or SRA), "With Location" indicates a non-empty geo_loc_name BioSample attribute; "With Date" indicates a non-empty collection_date; "With Both" requires both fields present. The data availability table can be filtered by source (Genomes only, SRA only, or combined).

Visualisations

Geographic distribution: The geo_loc_name field is parsed to extract the country (text before the first colon), mapped to ISO 3166-1 alpha-3 codes, and displayed on a Natural Earth 110m equirectangular projection with a log-scale colour gradient. Combined genome + SRA data.

Genomes over time: Year-by-year counts of genome assemblies and SRA WGS runs. Default axis is collection_date (year), stacked by species (default) or priority group. A toggle switches to release_date for the publication view.

Sampling context: Stacked bars per species using the derived host category, with a toggle for absolute counts vs proportions. Raw host and isolation_source values are listed in the per-species table.

Submitting centres: Top submitting organisation per species, ranked by total record count (genomes + SRA). For genomes, the BioSample owner.name is preferred over the assembly-level submitter because RefSeq assemblies have a constant "National Center for Biotechnology Information" submitter that masks the original depositor. For SRA, the SUBMISSION center_name is used.

Limitations

  • SRA counts for genus-level queries may include non-pathogenic species within the genus.
  • Geographic parsing is approximate — entries with only sub-national locations (e.g. "California" without country prefix) may be missed.
  • Collection dates vary in precision (year only, year-month, or full date); only the year is used for temporal charts.
  • Host categorisation uses keyword matching against free-text fields and is therefore approximate. Ambiguous records fall into the unknown bucket; sanity-check using the raw values in the per-record CSV.
  • Submitter names are not curated. The same organisation can appear under multiple aliases (full name vs initialism vs department). Treat the top-N table as a ranking, not an exact dedup.
  • Some assemblies in NCBI are suppressed or superseded but still returned by the Datasets CLI.
